Smart Library Circulation and Automation System

This is a Java based Smart Library Circulation and Automation System developed for my assessment.

# Main Program

* App.java *  is the main entry point of the program. Running App.java starts and displays the graphical user interface.

The main GUI is implemented in * MainWindow.java * using Java Swing.

# Source Files

- App.java - Starts the application and displays the GUI
- MainWindow.java - Contains the main graphical user interface
- LibraryItem.java - Base class for library items
- Book.java - Represents book items
- Magazine.java - Represents magazine items
- Journal.java - Represents journal items
- Borrowable.java - Handles borrowable items
- LibraryDatabase.java - Manages library records
- ReservationQueue.java - Handles reservations
- SearchEngine.java - Handles searching
- SortEngine.java - Handles sorting
- UndoStack.java - Handles undo operations
- FileHandler.java - Handles saving and loading data

# How to Run

Run * App.java * to start the Smart Library application.
