# Smart Library Circulation and Automation System

This project is a Java based Smart Library Circulation and Automation System developed for my assessment.

# Main Program

* App.java * is the main entry point of the program. Running App.java starts and displays the graphical user interface (GUI).

# Source Files

- App.java - Starts and displays the GUI
- Book.java - Represents book items
- Borrowable.java - Handles borrowable item behaviour
- FileHandler.java - Handles saving and loading of data
- Journal.java - Represents journal items
- LibraryDatabase.java - Manages library records
- LibraryItem.java - Base class for library items
- Magazine.java - Represents magazine items
- MainWindow.java - Contains the main window components
- ReservationQueue.java - Manages reservations
- SearchEngine.java - Handles searching
- SortEngine.java - Handles sorting
- UndoStack.java - Handles undo operations

#  How to Run

Run * App.java * to start the application and display the GUI.
